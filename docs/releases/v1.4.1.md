# Codex Proxy Guardian v1.4.1

这是 `v1.4.0` 安装进度功能的健康验证热修版。

## 修复内容

Guardian 在安装或自动更新收尾阶段被外部意外终止时，可能已经写出一份停留在 `Stabilizing` 的 `status.json`。旧安装器只检查状态文件是否存在，可能在 Guardian 已经退出时仍然报告安装成功。

v1.4.1 会：

- 核对状态 PID 对应的进程命令行和完整 watcher 路径；
- 首次启动在健康验证期间退出时，清理过期状态后安全重试一次；
- 重试时继续保护已在运行的 Codex，并在进度界面显示“Guardian 异常退出，正在安全重试”；
- 两次都无法保持运行时明确安装失败并指向日志，不显示假的 100% 完成。

安装器仍不修改 Windows 系统代理、WinHTTP、DNS、路由或永久环境变量。

## 验证

- Windows PowerShell 5.1 自动化测试和 WinHTTP PAC 集成测试；
- PowerShell 7 与 Windows/macOS/Linux CI；
- Windows Setup EXE 编译、内嵌载荷自检与 12 个发布资产打包。
