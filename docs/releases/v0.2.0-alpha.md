# Codex Proxy Guardian v0.2.0-alpha

面向 Windows 11 Codex 桌面版的代理守护程序首个公开 Alpha 版本。

它会自动发现并验证当前可用的 HTTP/HTTPS 代理。当 Clash、Mihomo、v2rayN、sing-box 等代理程序的监听地址或端口稳定变化时，以进程级代理环境变量和 Chromium 代理参数受控重启 Codex。

## 主要能力

- 检测 Windows 当前用户系统代理、手动配置、代理环境变量和常见代理软件监听端口；
- 通过多个 OpenAI/ChatGPT HTTPS 目标验证代理，不只检查端口是否打开；
- 提供防抖、重启冷却、频率限制、熔断和启动失败恢复，降低 Codex 反复重启风险；
- Microsoft Store / MSIX 版 Codex 路径动态解析，支持 x64 与 ARM64；
- 当前用户静默自启，无需管理员权限；
- 状态、轮转日志、脱敏诊断、单实例保护和安全卸载；
- 默认 `Safe` 模式，不修改 Windows 系统代理、WinHTTP、DNS、路由或永久环境变量。

## 下载与安装

1. 下载 `CodexProxyGuardian-0.2.0-alpha.zip` 和对应的 `.sha256` 校验文件；
2. 解压 ZIP，在普通权限 PowerShell 中进入解压目录；
3. 执行：

```powershell
Unblock-File .\Install.ps1
.\Install.ps1
```

发布 ZIP 的 SHA-256：

```text
5b974f1814db0406b09b4fb393cf9eea75c4c42f8fb58074117d0c9b7edc32e0
```

安装后可用以下命令检查是否真正生效：

```powershell
.\Status.ps1
.\Doctor.ps1 -Online
```

`ValidatedProxy` 表示代理已通过在线验证，`LaunchConfigured` 表示 Codex 根进程带有匹配的代理参数，`TrafficObserved` 表示近期实际观察到 Codex 进程树连接该代理端点。

## Alpha 版本说明

这是预发布版本。不同 Windows 版本、Codex 分发渠道、代理软件和端口模式仍需要更多真实电脑验证。建议先使用默认 `Safe` 模式；暂不自动支持 PAC/WPAD、纯 SOCKS、只有 TUN 而没有 HTTP/混合端口的配置。

遇到问题请提交中文 Issue，并在提交前人工检查 `Doctor.ps1 -Online -Json` 的脱敏报告。不要公开代理账号密码、令牌、用户名、主机名或 IP 地址。

本项目是独立社区项目，与 OpenAI 没有隶属、认可或支持关系。
