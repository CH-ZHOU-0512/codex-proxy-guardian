# Codex Proxy Guardian v0.3.1-alpha

这是针对 `v0.3.0-alpha` 的安装安全热修版，代理守护行为保持不变。

## 修复内容

- 旧 Guardian 如果被外部终止，Windows 可能把它原来的 PID 分配给其他程序。旧安装器会安全地拒绝终止该进程，但也会阻止后续升级。
- 新安装器改为根据完整 `Watch-CodexProxy.ps1` 路径识别实际 Guardian 进程；发现状态文件中的 PID 已被复用时，只记录警告并替换过期状态。
- 安装器绝不会因为过期 PID 而终止无关进程，同时仍会等待或停止经过身份验证的旧 Guardian。

## 安装或升级

下载 `CodexProxyGuardian-0.3.1-alpha.zip` 和对应的 `.sha256` 文件，解压后在普通权限 PowerShell 中执行：

```powershell
Unblock-File .\Install.ps1
.\Install.ps1
```

已有配置会保留。安装器不会修改 Windows 系统代理、WinHTTP、DNS、路由或永久环境变量。

完整的 Safe/Enforce 行为、普通 Codex 启动方式与 Alpha 说明见项目 README。
