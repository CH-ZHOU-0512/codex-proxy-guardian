# Codex Proxy Guardian v1.2.0

这一版把 Codex Proxy Guardian 从 Windows 11 扩展到 macOS 和 Linux，并保留同一个原则：**先实际验证代理，再让 Codex 使用；不修改系统网络配置，也不因为猜测而反复重启。**

## macOS

- 提供 Intel（amd64）与 Apple Silicon（arm64）原生包；
- 读取 macOS 当前代理、继承的代理环境变量和常见代理程序本地监听端口；
- 通过当前用户 LaunchAgent 登录自启、静默运行；
- 守护 ChatGPT/Codex 桌面应用，在代理端点稳定变化后才受控修复；
- Safe 模式先等待实际流量证据，Strict 模式按参数一致性修复，两者都有防抖、冷却、次数限制和熔断。

## Linux

- 提供 x64（amd64）与 ARM64 原生包；
- 优先使用 systemd user，自身不可用时回退到 XDG Autostart；
- 安装 `codex-guard` 命令，用已验证代理启动官方 Codex CLI，并透传所有参数；
- 不会强杀或自动重启交互式终端里的 Codex 会话。

Linux 当前没有官方 Codex 桌面应用，因此本项目不把 CLI 包装能力宣传成桌面守护。直接运行普通 `codex` 仍取决于当前 shell 自己的环境；要确定使用 Guardian 当前验证过的代理，请运行 `codex-guard`。

## 下载与安装

在 Release 中选择与平台和架构完全匹配的文件：

- `CodexProxyGuardian-1.2.0-darwin-amd64.tar.gz`
- `CodexProxyGuardian-1.2.0-darwin-arm64.tar.gz`
- `CodexProxyGuardian-1.2.0-linux-amd64.tar.gz`
- `CodexProxyGuardian-1.2.0-linux-arm64.tar.gz`

下载对应 `.sha256` 可校验完整性。解压后以普通用户运行：

```sh
./install.sh
codex-proxy-guardian doctor
```

不要使用 `sudo`。卸载运行 `./uninstall.sh`；只有明确希望连配置和日志一起删除时才使用 `./uninstall.sh --purge`。

Windows 用户继续下载 `CodexProxyGuardian-Setup-1.2.0.exe` 一键安装，或使用版本 ZIP。

## 自动更新与验证

macOS/Linux 更新器固定访问本项目 Release，只接受当前 OS/架构对应的包；标签、语义版本、资产名、包内 `VERSION` 和 SHA-256 必须全部一致。压缩包还要通过条目数量、总大小、文件类型和路径穿越检查。

本版本在 Go 单元测试中覆盖代理规范化、候选优先级、真实 HTTP 代理请求、验证成功数门槛、Stable/Prerelease 选择、语义化预发布版本顺序和恶意归档拒绝，并对四个目标完成交叉编译。CI 还会在 GitHub 的 Windows、macOS、Linux 原生 Runner 上复核。

本项目仍是独立社区工具，不提供代理或节点，也不隶属于 OpenAI。桌面启动参数属于基于实际行为的兼容方案，不是 OpenAI 承诺长期不变的公开代理 API。
