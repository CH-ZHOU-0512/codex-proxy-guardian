# Codex Proxy Guardian v0.4.0-alpha

这一版把“模式切换”和“项目更新”变成普通用户不用编辑配置文件也能完成的功能。

## 模式设置

安装后从开始菜单打开 **Codex Proxy Guardian Settings**：

- **自动（推荐 / Safe）**：按每次 Codex 启动的实际代理流量自动判断；已经能通信就不动，确有必要时才受控修复。
- **严格（Enforce）**：只要根进程缺少当前代理参数，就在防抖和重启保护允许时校正。

模式变化由 Guardian 在后台热加载，不重启 Guardian，也不会主动关闭当前 Codex。命令行也可执行：

```powershell
.\Control.ps1 -Action SetMode -Mode Auto
.\Control.ps1 -Action SetMode -Mode Strict
.\Control.ps1 -Action ToggleMode
```

## 自动更新

默认创建每日当前用户任务 `Codex Proxy Guardian Update`。更新器只读取固定项目仓库的 GitHub Release，并要求以下信息全部一致：

- 更新通道允许该版本；
- Release 标签和语义版本更高；
- ZIP 与 `.sha256` 文件名对应目标版本；
- 下载 ZIP 的 SHA-256 与校验文件一致；
- GitHub 提供资产摘要时，该摘要也必须一致；
- ZIP 不包含越界路径，文件数量和展开大小不超过安全限制；
- 解压后的 `VERSION` 与 Release 标签一致。

安装前会快照当前文件；安装中断时会尝试回滚原版本并恢复原 Guardian。检查和更新结果写入 `logs\update-*.jsonl`。设置窗口可以关闭自动更新，或在 Stable 与 Prerelease 通道之间切换。Alpha 版本默认跟随 Prerelease。

手动检查或立即更新：

```powershell
.\Control.ps1 -Action CheckUpdate
.\Control.ps1 -Action Update
```

## 安装或升级

下载 `CodexProxyGuardian-0.4.0-alpha.zip` 和对应的 `.sha256` 文件，解压后在普通权限 PowerShell 中执行：

```powershell
Unblock-File .\Install.ps1
.\Install.ps1
```

已有代理、模式和重启保护配置会保留。安装器不会修改 Windows 系统代理、WinHTTP、DNS、路由或永久环境变量。
