# Codex Proxy Guardian v1.4.0

这一版改进 Windows 一键安装时的反馈：点击“立即安装”后，不再只看到一个无限旋转的动画，而是可以看到当前正在做什么以及 0–100% 进度。

## 进度是怎么计算的

- 读取和解压内嵌 ZIP 时，EXE 按实际已展开字节计算进度；
- 进入安装脚本后，按已完成的预检、代理连通性、文件复制、配置保留、登录自启、自动更新任务、快捷方式和 Guardian 健康状态分阶段更新；
- 百分比只会向前，不会因为异步消息而倒退；
- 某个阶段需要等待时，进度会停在当前值，阶段文字会说明正在等什么，不会伪造匀速增长。

## 兼容与安全

进度通信只在图形安装器调用 `Install.ps1` 时显式启用。用户手动运行脚本时，不会看到内部协议标记。安装器仍以当前用户身份运行，不修改 Windows 系统代理、WinHTTP、DNS、路由或永久环境变量。

## 验证

- Windows PowerShell 5.1 语法与进度协议预检通过；
- 40 项 PowerShell 自动化测试通过；
- 图形安装器在 .NET Framework 编译成功，内嵌载荷自检通过；
- Windows ZIP/EXE 及 macOS/Linux 四架构发布包均能生成。
