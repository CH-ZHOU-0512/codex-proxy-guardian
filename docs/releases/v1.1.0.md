# Codex Proxy Guardian v1.1.0

这一版把普通用户的安装流程从“解压 ZIP、打开 PowerShell、执行脚本”缩短为：**下载一个 EXE，双击，点击立即安装。**

## 新增一键安装器

- 正式 Release 新增 `CodexProxyGuardian-Setup-1.1.0.exe`；无需管理员权限，可完成首次安装或原位升级。
- EXE 内嵌与本次 Release ZIP 完全相同的项目文件，并在安装前核对内嵌版本与必需文件。
- 解压仅发生在独立临时目录，并限制文件数量、单文件大小、总展开大小和路径边界。
- 安装器使用系统自带 Windows PowerShell 调用现有 `Install.ps1`，不直接修改 Windows 网络配置；最长等待十分钟，失败会在临时目录留下安装日志。
- CI 会实际编译 EXE、运行 `--verify` 自检，并为 EXE 和 ZIP 分别生成 SHA-256 文件。

## 推荐安装方式

1. 下载 `CodexProxyGuardian-Setup-1.1.0.exe`；
2. 双击后确认窗口中的项目地址为 `CH-ZHOU-0512/codex-proxy-guardian`；
3. 点击“立即安装”；完成后继续照常打开 Codex。

本社区项目目前没有商业代码签名证书，因此 Windows SmartScreen 可能提示应用无法识别。请只从本仓库的正式 Release 下载；也可以下载 `CodexProxyGuardian-Setup-1.1.0.exe.sha256` 并核对 SHA-256。请勿为安装本项目关闭 Windows 安全功能。

## ZIP 仍然保留

需要审核脚本、受企业未签名 EXE 策略限制，或希望使用高级安装参数时，可以继续下载 `CodexProxyGuardian-1.1.0.zip` 与对应 `.sha256`，解压后运行：

```powershell
Unblock-File .\Install.ps1
.\Install.ps1
```

已有安装的每日自动更新仍使用经过多重校验的 ZIP，因此 v1.0.0 用户会照常升级到 v1.1.0，不需要重新下载 EXE。模式、更新通道和现有配置会保留。

## 安全边界不变

安装器和 Guardian 都以当前用户身份运行，不修改 Windows 系统代理、WinHTTP、DNS、路由或永久用户/系统环境变量。默认仍为“自动（Safe）”模式，所有 Codex 修复继续受到证据等待、防抖、冷却、频率限制和熔断保护。
