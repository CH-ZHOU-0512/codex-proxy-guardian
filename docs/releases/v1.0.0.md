# Codex Proxy Guardian v1.0.0

这是 Codex Proxy Guardian 的首个正式版本。它把代理发现、真实连通性验证、Codex 代理修复、模式设置和安全更新整合成普通用户安装一次即可长期运行的 Windows 11 工具。

## 主要功能

- **自动（推荐 / Safe）**：根据 Codex 的实际代理流量判断是否需要修复；已经能通信就保持不动。
- **严格（Enforce）**：根进程缺少当前代理参数时，在防抖、冷却、频率限制和熔断允许的范围内校正。
- 开始菜单提供 **Codex Proxy Guardian Settings**，无需编辑 JSON 即可切换模式、更新开关和通道。
- 模式变化由 Guardian 后台热加载，不重启 Guardian，也不会因为设置更新主动重启 Codex。
- 持续重新解析 Store/MSIX Codex 安装路径，适配 Codex 自身更新后的路径变化。

## 安全自动更新

新安装默认每天以当前用户身份检查 Stable Release。更新器固定到本项目仓库，并要求 Release 标签、语义版本、资产名称、包内 `VERSION`、`.sha256` 与 GitHub 资产摘要（提供时）一致。

更新包还必须通过路径与展开规模检查。安装前会快照现有文件；安装中断时会尝试回滚原版本并恢复 Guardian。已有安装会保留自己的模式、更新通道、任务名称和快捷方式设置。

## 已验证

- Windows PowerShell 5.1 与 PowerShell 7 测试通过；
- 本机真实 Store/MSIX Codex、系统 HTTP 代理和计划任务环境验证通过；
- 模式在严格与自动之间热切换时，Guardian PID 与 Codex PID 均保持不变；
- 每日静默更新任务真实运行并以退出码 0 完成；
- Guardian 状态为 Ready，代理有效且观察到 Codex 的真实代理流量；
- 不修改 Windows 系统代理、WinHTTP、DNS、路由或永久环境变量。

## 安装或升级

下载 `CodexProxyGuardian-1.0.0.zip` 和对应的 `.sha256` 文件，解压后在普通权限 PowerShell 中执行：

```powershell
Unblock-File .\Install.ps1
.\Install.ps1
```

本项目是独立社区工具，不是代理软件，也不隶属于 OpenAI。电脑上必须已经存在可用的 HTTP/HTTPS 代理。Codex 或 Windows 后续更新仍可能改变兼容行为，遇到问题请提交脱敏 Doctor 报告。
