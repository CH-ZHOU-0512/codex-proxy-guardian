# Codex Proxy Guardian v0.3.0-alpha

这一版重点解决一个普通用户最关心的问题：**安装一次以后，继续直接打开原来的 Codex，Guardian 也会自动运行并判断是否需要修复代理，不必每次先打开 PowerShell 或手动操作快捷方式。**

## 主要改进

- 默认 `Safe` 模式会检查普通方式启动的 Codex。缺少当前代理参数时，先等待 20 秒观察实际代理流量；已经能通过代理通信就保持不动，否则只进行一次受控重启。
- `Enforce` 模式的含义更明确：只要根进程缺少当前代理参数，就在防抖后校正，不使用 Safe 的流量证据豁免。
- 所有自动修复继续共用重启冷却、滑动次数限制和持久化熔断，避免异常检测造成无限重启。
- 改进 Microsoft Store / MSIX 清单解析，可根据应用 ID、常见可执行文件名和完整路径定位当前 Codex，并覆盖新版 `ChatGPT.exe` 布局。
- Store 更新期间如果暂时找不到替代可执行文件，会保留仍在运行的 Codex，不会先关闭再启动失败。
- `Status.ps1` 和脱敏 `Doctor.ps1` 报告新增外部启动策略、应用 ID、架构、可执行文件名和解析方式，便于定位不同电脑上的兼容性问题。
- 安装包现在携带准确的 `VERSION`，运行日志不再使用写死的旧版本号。

## 安装或升级

1. 下载 `CodexProxyGuardian-0.3.0-alpha.zip` 和对应的 `.sha256` 文件；
2. 解压 ZIP，在普通权限 PowerShell 中进入解压目录；
3. 执行：

```powershell
Unblock-File .\Install.ps1
.\Install.ps1
```

已安装旧版时，直接运行新版 `Install.ps1` 即可原位升级并保留现有配置。默认安装完成后立即启动，并在以后登录 Windows 时静默自启。

安装后可执行以下命令确认状态：

```powershell
.\Status.ps1
.\Doctor.ps1 -Online
```

`ValidatedProxy` 表示代理已通过在线验证，`LaunchConfigured` 表示 Codex 根进程带有匹配参数，`TrafficObserved` 表示近期实际观察到 Codex 进程树连接当前代理。

## Alpha 说明

真实机器覆盖仍在积累中，未来 Codex 或 Windows 更新也可能改变进程启动方式。解析失败时 Guardian 会保留现有进程并报告明确状态，不会猜测路径或修改 Windows 系统代理、WinHTTP、DNS、路由和永久环境变量。

遇到问题请提交 Issue，并附上人工检查后的 `Doctor.ps1 -Online -Json` 脱敏报告。不要公开代理账号密码、令牌、用户名、主机名或 IP 地址。

本项目是独立社区项目，与 OpenAI 没有隶属、认可或支持关系。
