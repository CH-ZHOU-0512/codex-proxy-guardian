# Codex Proxy Guardian v1.3.1

这是一个 Windows 自动更新兼容修复版。SOCKS5 与 PAC/WPAD 功能与 v1.3.0 一致。

## 修复内容

Windows PowerShell 5.1 在直接把 `Invoke-RestMethod` 放入数组表达式时，可能将 GitHub Releases 返回的整个 JSON 数组保留为一个管道对象。旧更新器因此无法看到其中的各个版本，并误报“已是最新版”。

v1.3.1 从两层修复该问题：

- REST 返回值先赋给变量，再显式枚举；
- Release 选择器也能展平 PowerShell 5.1 可能产生的嵌套数组形态。

## 已安装旧版的 Windows 用户

如果状态页长期停在 v1.0.0–v1.3.0，却始终显示没有更新，请从本 Release 下载新 Setup EXE 原位安装一次，或使用 ZIP 中的 `Install.ps1`。安装到 v1.3.1 后，后续正式版可继续按既有的每日更新任务自动检查。

更新仍会校验 Release 通道、版本、资产名称、包内 `VERSION` 和 SHA-256，不修改系统网络配置。
